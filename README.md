# Smart Health & Food Guide

A comprehensive health, nutrition, and lifestyle guidance platform that delivers personalized recommendations based on each user's health profile, goals, lifestyle, allergies, and medical conditions.

---

# Overview

Smart Health & Food Guide helps users make informed decisions about nutrition, exercise, hydration, and healthy living through personalized health assessments and intelligent recommendation generation.

The platform also provides a complete administrative system for managing foods, exercises, diseases, medical conditions, and recommendation protocols.

# Installation

Clone the repository

```bash
git clone https://github.com/koladecode/smart-health-food-guide-app.git
```

Install dependencies

```bash
npm install
```

Run the frontend

```bash
npm run dev
```

Run the backend

```bash
cd server
npm install
npm run dev
```
